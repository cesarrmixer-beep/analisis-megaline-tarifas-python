# analisis-megaline-tarifas-python
Análisis de plan tarifario de Megaline para encontrar cuál tarifa tiene mejor margen de ganancia. 

Análisis de el comportamiento de los clientes con su plan tarifario usando Python, Pandas, Numpy, Scipy, Seaborn y Matplotlib

## 🎯 Objetivo de negocio 
Realizar un análisis preliminar de las tarifas basado den una seleccion de clientes

## 🛠 Herramientas 
-  Python, Pandas, Numpy, Scipy, Seaborn y Matplotlib
-  Limpieza de datos, EDA, Cálculos de metricas por usuario, Calculo de ingresos mensuales, Estadísticas descriptivas y Prueba de hipótesis estadisticas

## 📊 Hallazgos clave 
- Los ingresos que deja el plan Surf reflejan que esta tarifa debe seguir siendo empujada al consumidor, ya que los veneficios inmediatos para la compañia seran constantes.
- El plan Ultimate puede seguir figurando ya que es un método seguro de generar ganancias ya que siempre quedaran recursos(minutos, mensajes, mb) a favor de la empresa, y estos no serán       reembolsados ni descontados de facturas siguientes.
